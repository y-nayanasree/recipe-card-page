
# 💎 Recipe Card Page

A responsive recipe card website featuring a creamy herb pasta recipe.

## Features
- Recipe image with caption
- Preparation and cooking time
- Servings information
- Ingredients list
- Numbered preparation instructions
- Responsive design for mobile and desktop
- Clean card layout with CSS hover effects

## Technologies Used
- HTML5
- CSS3
- JavaScript (optional enhancement)

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. View the recipe ingredients and preparation steps.

## Project Structure
- `index.html` — Recipe content and page structure
- `style.css` — Styling and responsive layout
- `script.js` — Optional JavaScript enhancement
- `README.md` — Project documentation
